# Function: poleBonus()

> **poleBonus**(`height`): `number`

Bonus for grabbing the finish pole at `height` (0 bottom to 1 top): 100 at
the foot, 2000 near the top, in five steps. A full jump timed to peak at
the pole reaches the top step.

`number`
