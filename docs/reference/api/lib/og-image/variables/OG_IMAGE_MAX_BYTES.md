# Variable: OG\_IMAGE\_MAX\_BYTES

> `const` **OG\_IMAGE\_MAX\_BYTES**: `number`

Upper bound for a rendered card. WhatsApp drops link previews around
300 KB, so cards stay under 250 KB with headroom (ADR 0053).
