# Function: isTextEntryTarget()

> **isTextEntryTarget**(`target`): `boolean`

Whether a key landed in a text-like field: a text input, a textarea or a
contenteditable region. A checkbox, range or button is not one.

## Parameters

### target

`EventTarget` \| `null`

The event target.

## Returns

`boolean`

True when the key belongs to the field.
