# Function: isLevelGolfed()

> **isLevelGolfed**(`score`): `boolean`

Whether a saved score carries the Golfed badge. Only an honest, completed
score can; a score saved before the badge existed reads as not golfed.

## Parameters

### score

[`LevelScore`](../../types/interfaces/LevelScore.md) \| `null` \| `undefined`

The saved score, if any.

## Returns

`boolean`

True when the level shows the badge.
