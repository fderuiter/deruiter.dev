# Type Alias: EchoPhase

> **EchoPhase** = `"showing"` \| `"input"` \| `"over"`

Where a round stands. `showing`: the vault is playing the sequence and
ignores input. `input`: the player is repeating it. `over`: a wrong pad
ended the round.
