# Function: isControlTarget()

> **isControlTarget**(`target`): `boolean`

Whether a key landed on a control that owns Space and Enter: a button, a
link, a select, a non-text input, or an element with a button, link, menu
item or tab role.

## Parameters

### target

`EventTarget` \| `null`

The event target.

## Returns

`boolean`

True when the focused element is such a control.
