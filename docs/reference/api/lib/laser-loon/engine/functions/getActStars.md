# Function: getActStars()

> **getActStars**(`clearSeconds`, `parSeconds`, `hitsLost`): `1` \| `2` \| `3`

Stars for a cleared act: one for clearing it, one for beating its par
time, and one for losing no hits.

## Parameters

### clearSeconds

`number`

Seconds of unpaused play the act took.

### parSeconds

`number`

The act's par time.

### hitsLost

`number`

Hits the loon took during the act.

## Returns

`1` \| `2` \| `3`
