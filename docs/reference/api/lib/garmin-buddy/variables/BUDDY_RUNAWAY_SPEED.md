# Variable: BUDDY\_RUNAWAY\_SPEED

> `const` **BUDDY\_RUNAWAY\_SPEED**: `3` = `3`

A runaway buddy's speed: faster than a run (2.5 px per frame) and slower
than a sprint (3.75), so only a sprint catches it.
