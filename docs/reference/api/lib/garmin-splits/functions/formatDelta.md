# Function: formatDelta()

> **formatDelta**(`ms`, `best`): `string`

Signed difference from a best: "-0:01.20" when faster, "+0:00.45" when
slower, and "" when there is no finite best or the time is not finite.

### ms

`number`

### best

`number` \| `undefined`
