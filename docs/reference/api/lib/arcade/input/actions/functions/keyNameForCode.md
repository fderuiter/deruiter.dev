# Function: keyNameForCode()

> **keyNameForCode**(`code`): `string`

The name a player reads for a physical key: `KeyQ` is "Q", `Digit1` and
`Numpad1` are "1", `ArrowUp` is "↑".

## Parameters

### code

`string`

A `KeyboardEvent.code` value.

## Returns

`string`

The key's printed name.
