# Interface: HintOptions

Options for the coach's line.

## Properties

### coop?

> `readonly` `optional` **coop?**: `boolean`

True in two-player play. Each person then gets a different starting job,
so the two coach lines never repeat each other.

***

### touch?

> `readonly` `optional` **touch?**: `boolean`

True on a touch iPad (#2123): the line names the on-screen keys (Use,
Work) instead of the keyboard's.
