# Variable: EXHAUSTION\_RULE

> `const` **EXHAUSTION\_RULE**: `"At 0 GB the simulated tactic session stops and the level must be reset, in either mode. Every tactic, sorry included, stays locked until then."` = `"At 0 GB the simulated tactic session stops and the level must be reset, in either mode. Every tactic, sorry included, stays locked until then."`

The 0 GB rule as the player reads it. The HUD, the Theory Briefing and
`getTacticBlock` all use this one sentence, so the copy and the engine
cannot drift apart.
