# Function: arcadeDailySeed()

> **arcadeDailySeed**(`date`, `game`): `number`

The shared Arcade Daily seed for a game on a UTC date: an unsigned 32-bit
integer, the same in every browser. Throws a RangeError on anything but a
real date.

## Parameters

### date

`string`

### game

`"trial-and-error"` \| `"for-better-or-bulk"` \| `"study-director"` \| `"patty-drive-thru"` \| `"protocol-drift"`

## Returns

`number`
