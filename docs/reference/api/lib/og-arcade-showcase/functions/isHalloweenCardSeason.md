# Function: isHalloweenCardSeason()

> **isHalloweenCardSeason**(`date`): `boolean`

Whether the October link preview is in season: any moment of October on
the site's home clock (US Central). UTC would turn the card back at 7 PM
on Halloween itself.

## Parameters

### date

`Date`

The moment to check.

## Returns

`boolean`

True through October in US Central time.
