# Function: runBlinds()

> **runBlinds**(`plan`, `run`): `object`[]

The Blinds the current act plays, in order, as the run's sponsor and stake
rewrite them. An act with a boss pool contributes its Small and Big Blinds
and the Boss the run drew.
