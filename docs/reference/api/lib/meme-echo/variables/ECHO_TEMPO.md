# Variable: ECHO\_TEMPO

> `const` **ECHO\_TEMPO**: `object`

The playback tempo schedule. Each sequence step lasts `baseMs`, and the
step shortens by `stepMs` for every `every` pads the sequence holds, never
going below `minMs`.

## Type Declaration

### baseMs

> `readonly` **baseMs**: `640` = `640`

### every

> `readonly` **every**: `3` = `3`

### minMs

> `readonly` **minMs**: `320` = `320`

### stepMs

> `readonly` **stepMs**: `40` = `40`
