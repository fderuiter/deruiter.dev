# Function: spinCape()

> **spinCape**(`state`): [`GameEngineState`](../interfaces/GameEngineState.md)

Spins the Compression Cape: for [CAPE\_SPIN\_MS](../../cape/variables/CAPE_SPIN_MS.md) it defeats bugs and
watchdogs beside the runner and bumps Sync Blocks from the side. Only a
Cape runner can spin, once per [CAPE\_SPIN\_COOLDOWN\_MS](../../cape/variables/CAPE_SPIN_COOLDOWN_MS.md).
