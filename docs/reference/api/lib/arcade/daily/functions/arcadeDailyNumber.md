# Function: arcadeDailyNumber()

> **arcadeDailyNumber**(`date`, `game`): `number`

The daily seed as a whole number from 1 to [ARCADE\_DAILY\_MAX\_SEED](../variables/ARCADE_DAILY_MAX_SEED.md),
for games whose seeds are positive integers. Never 0, which some games
keep for their standard, unseeded run.

## Parameters

### date

`string`

### game

`"trial-and-error"` \| `"for-better-or-bulk"` \| `"study-director"` \| `"patty-drive-thru"` \| `"protocol-drift"`

## Returns

`number`
