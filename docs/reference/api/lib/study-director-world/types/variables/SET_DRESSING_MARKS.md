# Variable: SET\_DRESSING\_MARKS

> `const` **SET\_DRESSING\_MARKS**: readonly \[`"printout"`, `"travelPin"`, `"fileOverflow"`, `"sponsorMail"`, `"crisisMeeting"`, `"cup"`, `"smoke"`, `"fire"`, `"lunch"`, `"deserted"`, `"lateLamp"`\]

The set dressing a room's `marks` can carry. A mark repeated `n` times
means `n` of that thing, so four `"cup"` marks are four cups.
