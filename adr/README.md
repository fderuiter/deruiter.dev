# Architecture Decision Records

Each record captures the context, the decision, and the consequences of one
architectural choice. Records are append-only history: when a decision
changes, a new ADR supersedes the old one and the old record's Status says
so, rather than its body being rewritten.

New records are created with `npm run scaffold adr "<title>"`, which picks
the next number. Add the new record to this index in the same pull request.
